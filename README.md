# BTS/MRT Traffic Map (built site)

Static build of the BTS/MRT Traffic Map web app (build 2368c38c7543). Source is kept in a private repository.

Data: stations from Wikidata (CC0); some coordinates from the OTP Namtang GTFS
(สนข./OTP, CC-BY 4.0); track alignment, Chao Phraya River and Lumphini Park
© OpenStreetMap contributors (ODbL 1.0); headways transcribed from operator
publications (BTSC/EBM, BEM, SRTET). Optional unofficial live arrivals are
fetched by each visitor's browser from bangkoktransit.com (not affiliated
with BTS).
